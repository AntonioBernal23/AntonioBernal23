## 🚀 Proyectos destacados

### 🧠 CUT IA — Detección de comportamientos en el aula

**Visión artificial · Inteligencia artificial · Backend · Edge Computing**

Proyecto de visión artificial orientado a detectar comportamientos dentro de un entorno educativo mediante modelos YOLO y una cámara conectada a una Raspberry Pi 5.

**Tecnologías:** `Python` `YOLO` `OpenCV` `FastAPI` `Spring Boot` `Docker` `Raspberry Pi 5`

- 🎯 Detección de comportamientos como levantar la mano, leer, escribir y permanecer de pie.
- 📷 Procesamiento de imágenes y vídeo mediante visión artificial.
- 🔗 Integración entre el backend de inteligencia artificial y los servicios backend.
- ⚙️ Pruebas de inferencia en CPU y despliegue en dispositivos de recursos limitados.

### ♻️ ReciCUT — Aplicación web

**Desarrollo web · Integración backend · Bases de datos**

Proyecto de desarrollo web que incluye una aplicación frontend construida con Angular y trabajo de integración con servicios backend.

**Tecnologías:** `Angular` `TypeScript` `Java` `Spring Boot` `MySQL` `Docker`

- 🎨 Desarrollo de interfaces web y organización mediante componentes.
- 🔐 Trabajo con autenticación e integración de aplicaciones.
- 🔗 Comunicación entre el frontend y las APIs backend.
- 🗄️ Integración de bases de datos y entornos de desarrollo con contenedores.
